# `plugin/commands/`: slash commands

Claude Code slash commands for the daily routine: `/lead-magnet` (a brief to an editable
draft), `/publish` (a reviewed draft to a live form), `/connect` (a destination and a test
lead packet) and `/leads` (recent scored submissions). Each one calls the `mcpform` command
or the hosted MCP tools and nothing else (kit rule 3).

State: skeleton. Built by the platform's T4 with `mcpform login`, then each task that adds
an operation.
