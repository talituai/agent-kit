# Security

Report a vulnerability in this kit, the `mcpform` command, the `mcpform` Python client or
the MCPForm.io service to **security@mcpform.io**. Do not open a public issue for it.

Include what you found, how to reproduce it and what you believe it exposes. We acknowledge
within two working days, keep you informed and credit you if you wish once it is fixed.

This repository holds no customer data and no secret by rule. A token, key or real lead found
in it is itself a defect: report it the same way.
